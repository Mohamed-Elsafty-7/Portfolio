# Mohamed Elsafty | Developer Portfolio

A personal portfolio website showcasing my journey in software development, including web development projects, Python applications, and my ongoing exploration of back-end development with PHP.

## 🌐 Live Demo

[Visit My Portfolio](https://mohamed-elsafty-7.github.io/Portfolio/)

## ✨ Features

- **Home:** Introduction and overview of my development journey.
- **About:** Educational background, technical skills, and interests.
- **Projects:** A collection of projects with category filters for web development, Python, and back-end development.
- **Contact:** Contact information and a form with client-side validation.
- **Responsive Layout:** Designed to work across different screen sizes.
- **Pixel-Art Theme:** A dark, Minecraft-inspired visual identity with game-like styling and animations.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Remix Icon
- Google Fonts — VT323

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Mohamed-Elsafty-7/Portfolio.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No build tools are required for the static portfolio.

## 📂 Main Pages

- `index.html` — Home
- `about.html` — About Me
- `projects.html` — Projects
- `contact.html` — Contact

This portfolio documents my progress as a student developer and provides a central place to explore my projects, technical interests, and practical experience.
